Préparer le rapport

Le message est préparé ici. Vous vérifiez son contenu puis choisissez vous-même le groupe ou le destinataire WhatsApp. Les boutons Excel et PDF créent un fichier avec les chiffres validés : sur téléphone, le menu de partage s'ouvre (WhatsApp, e-mail…) ; sur ordinateur, le fichier est téléchargé.
